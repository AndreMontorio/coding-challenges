# 💻 Coding Challenges

My solutions to programming challenges from [HackerRank](https://www.hackerrank.com) and [LeetCode](https://leetcode.com), platforms that help developers sharpen their problem-solving skills through hands-on problems across many programming languages.

## 🎯 Purpose

This repository documents my progress on coding challenge platforms: exploring different approaches to problems, recording the reasoning behind each solution, and sharing working examples with other developers.

## 🛠 Repository Structure

Each platform has its own folder, organized the way that platform categorizes its problems, and its own README with the naming conventions and the full solutions index.

```
coding-challenges/
├── hackerrank/          # domain → subdomain → problem
│   ├── algorithms/
│   │   ├── warmup/
│   │   └── implementation/
│   └── README.md
├── leetcode/            # difficulty → problem
│   ├── easy/
│   └── README.md
├── LICENSE
└── README.md
```

| Platform | Organized by | Solutions Index |
| --- | --- | --- |
| [HackerRank](https://www.hackerrank.com) | domain → subdomain | [hackerrank/README.md](hackerrank/README.md) |
| [LeetCode](https://leetcode.com) | difficulty | [leetcode/README.md](leetcode/README.md) |

### Conventions

- The file extension indicates the solution language (`.js`, `.py`, `.sql`, ...).
- Every solution file starts with a standard header: problem name, link, category/difficulty, the task in my own words, the approach and its complexity. The exact format for each platform is in its README.
- Every new solution gets a row in its platform's solutions index.

## 🚀 Contributing

If you'd like to contribute new solutions, optimizations or improvements to existing ones, feel free to fork the repository and open a pull request.

1. Fork this repository.
2. Create a branch for your change (`git checkout -b feature/new-solution`).
3. Add the solution under the matching platform folder, following that platform's conventions, and update its solutions index.
4. Commit your changes (`git commit -m 'Add solution for [challenge]'`).
5. Push the branch (`git push origin feature/new-solution`).
6. Open a pull request.
